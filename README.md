## 🚀 Portfolio Website Stack

Este repositorio contiene mi sitio web de portfolio desarrollado con:

- **Framework:** Next.js 15 (App Router)
- **Lenguaje:** TypeScript
- **Estilos:** TailwindCSS 4
- **Validación:** Zod
- **Renderizado:** Static Site Generation (SSG)

### 📦 Instalación Local

```bash
# Instalar dependencias
npm install

# Desarrollo
npm run dev

# Build de producción
npm run build

# Ejecutar build localmente
npm run start
```
